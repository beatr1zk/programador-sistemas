# Programador de Sistemas
Repositório criado para armazenar os projetos, exercícios e atividades desenvolvidos durante o curso **Programador de Sistemas**.

Ao longo do curso, aprofundo meu conhecimento em **desenvolvimento de sistemas e tecnologias voltadas ao back-end**, explorando desde conceitos fundamentais de programação até o desenvolvimento de aplicações completas.


# Tecnologias e Ferramentas
Durante o curso, são utilizadas as seguintes tecnologias e ferramentas:
- *Visual Studio Code*
- *HTML5*
- *CSS3*
- *MySQL*
- *Python*
- *Django*


## Conteúdos do Repositório
Este repositório reúne os exercícios, projetos e práticas desenvolvidos ao longo do curso, acompanhando minha evolução no aprendizado de programação e desenvolvimento de sistemas.
